# Система управления сотрудниками

Полнофункциональная система управления сотрудниками с PIN-авторизацией, расписанием, расчетом зарплаты и интеграцией с Telegram.

## 🚀 Быстрый старт в Docker

### Способ 1: Docker Compose (рекомендуется)

```bash
# Собрать и запустить контейнер
docker-compose up -d

# Приложение будет доступно по адресу:
# http://localhost:8080
```

### Способ 2: Docker build

```bash
# Собрать Docker образ
docker build -t employee-management .

# Запустить контейнер
docker run -d -p 8080:80 --name employee-app employee-management

# Приложение будет доступно по адресу:
# http://localhost:8080
```

## 📋 Полезные команды Docker

```bash
# Просмотр запущенных контейнеров
docker ps

# Остановить контейнер
docker-compose down
# или
docker stop employee-app

# Просмотр логов
docker-compose logs -f
# или
docker logs -f employee-app

# Перезапустить после изменений
docker-compose up -d --build

# Удалить образ
docker rmi employee-management
```

## 🔐 Доступ к системе

### Администратор
- **PIN-код:** `0000`
- Доступ ко всем функциям управления

### Сотрудники
- Создаются администратором в разделе "Сотрудники"
- Каждый получает уникальный PIN-код

## ✨ Основные возможности

### Для администратора:
- 👥 Управление сотрудниками (добавление, редактирование, удаление)
- 📅 Составление расписания с цветовой маркировкой опозданий
- 💰 Расчет зарплаты (аванс + зарплата)
- 📊 Формирование отчетов в Excel
- ⚠️ Начисление штрафов
- 📱 Telegram уведомления
- 👤 Личный профиль (не редактируется из списка сотрудников)

### Для сотрудников:
- 📊 Итоги работы (смены, часы, статусы)
- 💰 Начисления (зарплата, премии, штрафы)
- 📅 Просмотр расписания

## 🎯 Правила расчета

### Аванс (1-15 число):
- **Почасовые:** фактическая ставка × часы за период
- **Оклад:** 40% от оклада

### Зарплата (16-конец месяца):
- **Почасовые:** ставка × часы + премия - штрафы
- **Оклад:** 60% от оклада + премия - штрафы

### Учет времени:
- Отклонение < 15 минут → округляется до планового времени
- Отклонение ≥ 15 минут → помечается цветом (опоздание/ранний уход)

## 📱 Telegram интеграция

Для работы Telegram уведомлений:
1. Создайте бота через @BotFather
2. Получите токен бота
3. Укажите токен в настройках администратора
4. Добавьте Telegram ники сотрудников при создании

Уведомления отправляются:
- При изменении расписания
- В начале рабочего дня
- В конце рабочего дня

## 🔧 Настройка

### Изменение порта в Docker

В файле `docker-compose.yml` измените:
```yaml
ports:
  - "ВАШ_ПОРТ:80"
```

### Хранение данных

Данные хранятся в LocalStorage браузера. Для персистентного хранения рекомендуется подключить базу данных.
